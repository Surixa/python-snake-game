# 🐍 Python Snake Game

A classic Snake Game developed using Python and the Turtle graphics library.

## Features
- Snake movement using arrow keys
- Random food generation
- Snake growth after eating food
- Real-time score tracking
- Wall collision detection
- Self-collision detection
- Game Over functionality

## Technologies Used
- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)

## Project Structure
- `main.py` – Main game loop and screen configuration
- `snake.py` – Snake creation, movement and extension
- `food.py` – Food generation and repositioning
- `score_board.py` – Score tracking and Game Over display

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python main.py
```

## Controls

| Key | Action |
|---|---|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

This project helped me practise Python classes, objects, inheritance, instance methods, object interaction, and game development logic.
